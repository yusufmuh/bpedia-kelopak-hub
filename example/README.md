# Contoh Zona Hadiah Kelopak

Aplikasi contoh paket `kelopak_hub`: zona Hadiah, tiga game (Check-in Harian,
Roda Sabtu, Misi Belanja), widget tanam Beranda, dan panel demo, di atas
backend lokal tanpa server.

```sh
cd example
flutter pub get
flutter run -d chrome      # web
flutter run -d <perangkat> # android
```

Runner `android/` dan `web/` ikut repo. Aplikasi contoh memakai kunci debug
untuk rilis dan tidak untuk diterbitkan.
