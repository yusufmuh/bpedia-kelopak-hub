## 4. Brand guideline resmi (38 halaman, `02_Brand Guidline`)

- **Identitas:** Bpedia (dulu Beautypedia), toko kecantikan online 100% original. Visi: teman belanja kecantikan paling dipercaya di Indonesia. Tagline: "Belanja Bikin Bahagia." (Fraunces SemiBold Italic).
- **Warna:** 60·30·10 — Pearl/putih latar, Blush/Tulip panel, Pink/Berry hanya untuk CTA & harga. Tombol pink-600 `#D81F57` + label putih (4,94:1); harga Berry `#B3164B`; teks Plum `#45122B`; sekunder Ink-700. Jangan teks putih di atas Petal `#F7729A` (2,68:1). Tema gelap "Berry Night".
- **UI kit:** tombol pil tinggi 52, label 16 SemiBold, satu tombol primer per layar; chip pil; badge radius 6 ("-40%" putih di pink, "Original" success, "Baru" honey); kartu produk putih radius 16 + border 1,5 px + shadow-card; sheet radius 24; target sentuh 48 dp; grid 8-pt, margin 16, jarak section 32.
- **Tipografi:** Poppins 400–800 untuk semua UI (display 28/34, judul 22/28, headline 18/24, body 16/24, body-s 14/20, caption 12/16, harga 18/24 w800). Fraunces italic hanya tagline. Tanpa ALL CAPS.
- **Ikon:** set SVG 24 px stroke 1,8 (mono untuk tab bar/UI padat, duotone untuk konten).
- **Bipy:** gadis chibi bertudung tulip pink (bukan lebah), rambut bob, gaun pink dengan "B". Pose: Wink (default), Senyum (info/CS), Ngintip (berita/kosong), Dalam tas (promo/paket), Berdiri (edukasi), Menyapa (onboarding). Satu Bipy per desain, jangan redraw/varian AI; file 2D `cha1 1.png` & `maskot pose hai.png` tidak sesuai aturan.
- **Voice:** hangat · ceria · jujur; sapa pelanggan "Babes"; tanpa hard-sell dan tanpa klaim "memutihkan/menyembuhkan/permanen".
- **Suara notifikasi:** motif "Bi-py" E6 → A6 (bel kaca), ≤ 2,5 dtk, jangan diputar ulang < 30 dtk, hormati mode senyap & jam tenang 21.00–08.00 WIB.
- **App icon:** "Utama" = wordmark + kepala Bipy; label di bawah ikon maks. 12 karakter.
- **Cacat file token:** `bpedia-tokens.css` punya `}}` ganda di kelas tipografi; `tokens.json` adalah sumber yang bersih. Font hanya WOFF2 (subset Latin 217 glyph, tanpa ★ → ≥ ♥).

## 5. Audit kode v1 (sebelum rombakan) — ringkasan

Hasil saat audit: `flutter analyze` bersih di 4 repo; 20 tes (19 fungsi murni + 1 smoke test). 39 temuan, utama:
- **Tinggi:** ekonomi sepenuhnya di klien tanpa persistensi (state hilang saat restart); roda berhenti di sektor Kelopak saat menang produk (cek `'produk'` case-sensitive).
- **Sedang:** "Lompat ke Sabtu" mendarat di Senin; tanggal beku 23 Nov 2026 (jam asli tidak dipakai); streak putus tetap ditampilkan; hak produk hari ke-30 tidak diumumkan; AppBar overflow di 320–393 dp; target sentuh 20 dp & kontras 3,68:1; panel QA ikut di build rilis; roda berputar mundur saat ganti hari; odds hard-code terpisah dari undian PHP; iOS Reduce Motion (flag `reduceMotion`) tidak dibaca; voucher misi bisa ditumpuk di satu pesanan (PHP); build rilis bertanda tangan debug, label `kelopak_hub`, ikon default.
- **Dokumen tidak akurat:** Bipy disebut "lebah"; palet `#982149` bukan palet brand; `ref: v1.0.0` padahal tag belum ada; checklist kepatuhan ditandai [x] padahal belum ada; `kelopak.gamysuf.fun` NXDOMAIN; auto-deploy Git tidak bisa mempublikasikan build web (build/ di-ignore); tautan `file:///` di README/PRD akar; email akun hosting tercantum di PRD repo publik.
- **Lingkungan lokal:** PHP 8.4 tanpa php.ini → `pdo_sqlite` tidak aktif → simulator membalas 503. Jalankan dengan `php -d extension_dir=<php>/ext -d extension=pdo_sqlite -S ...`.

Semua temuan tingkat Tinggi/Sedang di sisi app ditangani di v2 (engine + persistensi lokal, jam WIB nyata + Mode Demo, odds dari konfigurasi yang sama dengan undian, desain ulang total). Sisa yang perlu diputuskan/dikerjakan backend: server otoritatif, Idempotency-Key, webhook pesanan ber-HMAC, kuota promo nyata.

## 6. Paket & API Flutter terverifikasi (Flutter 3.41.7 / Dart 3.11.5)

Diverifikasi dengan `flutter pub get` + `flutter analyze` di proyek uji sementara. Versi lebih baru (audioplayers 6.8.x, flutter_svg 2.4+, flutter_native_splash 2.4.8) **tidak resolve** di SDK ini.

| Paket | Constraint | Catatan API |
|---|---|---|
| audioplayers | `^6.7.1` | SFX: `AudioPool.createFromAsset(path: 'audio/x.mp3', maxPlayers: n)` → `pool.start(volume:)` mengembalikan `StopFunction`. Prefix AudioCache default `assets/`. Jangan bergantung pada `PlayerMode.lowLatency` (dideprekasi di 7.x; tanpa event selesai). BGM: `AudioPlayer` + `setReleaseMode(ReleaseMode.loop)` + `AssetSource('audio/bgm_jingle.mp3')` (bisa ada jeda kecil saat loop). Web: suara hanya setelah gestur pengguna. |
| shared_preferences | `^2.5.6` | API legacy akan dideprekasi → pakai `SharedPreferencesAsync` (`getString`/`setString`/`remove`). Di Android memakai DataStore (beda store dari legacy). Web: LocalStorage per origin → prefix kunci. |
| flutter_svg | `^2.3.4` | `SvgPicture.asset(path, colorFilter: ColorFilter.mode(c, BlendMode.srcIn), semanticsLabel:)`. Parameter `color` deprecated. |
| flutter_launcher_icons | `^0.14.4` (dev) | Adaptive dibuat hanya jika `adaptive_icon_foreground` **dan** `adaptive_icon_background` diisi. `remove_alpha_ios: true`. Blok `web:` memperbarui manifest. |
| flutter_native_splash | `^2.4.7` (dev, tanpa preserve/remove) | `color`, `image`, `color_dark`, `image_dark`, `android_12: {color, image, ...}`. Logo Android 12: 960×960 dalam lingkaran 640 bila pakai `icon_background_color`. |

Web: tidak ada flag `--web-renderer` (default canvaskit/dart2js). `--base-href` di Git Bash butuh `MSYS_NO_PATHCONV=1`. Opsi `--no-web-resources-cdn` untuk menyajikan CanvasKit sendiri.
